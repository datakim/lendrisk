# Changelog

## 0.1.0a1 — 2026-10-04

Initial alpha: point-in-time cash-flow features, revenue-linked payment paths
with optional floors/milestones, monthly term-loan schedules, deterministic
revenue stress scenarios, credit diagnostics, PSI, dated returns, synthetic
examples, and an optional OptBinning adapter.

Includes English/Korean READMEs, calculation conventions, project research and
roadmap, numerical regression tests, CI, and wheel/source packaging. Distributed
through a GitHub version tag; PyPI publication remains a separate step.
