# Presentation references

The README and onboarding were redesigned on 2026-10-04 after inspecting
[GitHub Trending](https://github.com/trending) and the primary repository READMEs
below. Trending changes over time; this records a snapshot, not a continuing ranking.

| Repository observed on Trending | Presentation observed | Applied here |
| --- | --- | --- |
| [Impeccable](https://github.com/pbakaus/impeccable) | A short opening description and an immediately visible quickstart | A complete first-run example before the detailed API |
| [Effect](https://github.com/Effect-TS/effect) | Direct installation, explicit requirements, separate documentation links | Tagged install command, Python requirement, and a searchable guide |
| [LongCat-Video](https://github.com/meituan-longcat/LongCat-Video) | A recognizable SVG identity, visual demonstration, and task-oriented execution sections | Original branding, calculated financing/binning charts, and separate tutorials |
| [OpenCut](https://github.com/OpenCut-app/OpenCut) | Clear explanation of current project status | Visible alpha scope and honest current limitations |

These are presentation references. No artwork, logo, documentation text, or code
was copied from these projects. They do not endorse lendrisk. This research does
not establish that a visual style causes adoption or Trending placement.

## Keep the examples useful

Each guide explains the question, inputs, complete code, result interpretation,
and a next step. Charts use deterministic synthetic data and actual package
outputs. The score-scale figure is explicitly a mathematical mapping.

Run `python examples/visual_walkthrough.py` from the repository root to regenerate
the PNG and SVG figures, the banner, the scenario summary, and the binning table.
Keep the data provenance and assumptions visible when adding new figures.
